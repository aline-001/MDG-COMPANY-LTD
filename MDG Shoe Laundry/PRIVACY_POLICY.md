## 5. Data Security

### 5.1 Security Measures

We implement comprehensive security measures:

- **Encryption:** SSL/TLS encryption for data in transit
- **Password Security:** Bcrypt hashing for stored passwords
- **Access Controls:** Role-based access restrictions
- **Firewalls:** Network security firewalls
- **Regular Audits:** Security assessments and vulnerability testing
- **Secure Databases:** Protected database infrastructure
- **Admin Authentication:** Multi-factor authentication for admin accounts

### 5.2 Data Protection

- Regular security updates and patches
- Employee confidentiality agreements
- Limited access to sensitive data
- Secure deletion procedures
- Incident response plan
- Data backup and recovery procedures

### 5.3 Limitations

While we implement strong security measures, no system is completely secure. We cannot guarantee absolute security of your information. Transmission over the internet carries inherent risks.

We retain personal information:

- **Account Information:** Until account deletion or 3 years of inactivity
- **Order Information:** For 7 years (legal/tax requirements)

## 8. Children's Privacy

Parental consent is required for users aged 13-18. We recommend that parents review this policy with their teens.
